# Cuestionario: Fuentes de información médica

Sitio estático para repasar el PDF de clase sobre fuentes de información médica confiable, bases de datos médicas, bibliotecas digitales, PubMed/MeSH, tipos de estudio, ensayos clínicos y gestores bibliográficos.

## Publicar en Vercel
1. Extrae el ZIP.
2. Entra a https://vercel.com/drop
3. Arrastra la carpeta o el archivo ZIP descomprimido, según las opciones que te muestre Vercel.
4. Pulsa Deploy.

El archivo principal es `index.html`. Las preguntas se basan en el documento de clase; no se proporcionó una clave oficial de respuestas.
